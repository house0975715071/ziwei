# 紫微斗數 免費排盤（網頁版）

輸入生日與時辰，就能在手機或電腦上排出紫微斗數命盤，並用圖表看懂自己比較偏向哪一面：

- **五大面向雷達圖**：事業、財運、家庭、感情、健康，形狀往哪邊凸，就是你比較有優勢的方向
- **十二宮能量星狀圖**：十二個宮位的強弱一眼可比，點任何一宮看詳解
- **人生運勢曲線**：每十年一運（大限）的起伏，分早年、中年、晚年
- **適合的工作**、**今年流年**、**語音解說**（用你裝置內建的語音念）
- **完整報告**：可列印或存成 PDF

網址：https://house0975715071.github.io/ziwei/

## 隱私承諾

- 你輸入的生日只在你自己的手機或電腦裡計算，**不會送到任何伺服器**。
- 生日不會寫進網址，也不會存在瀏覽器裡；重新整理頁面，資料就消失了。
- 本站不用 cookie，不裝任何統計或追蹤碼，也不從其他網站載入字型或程式。
- 網站主機（GitHub Pages）跟所有網站一樣，會記錄一般的連線紀錄（例如 IP 位址與瀏覽時間），但不會拿到你輸入的生日。
- 語音解說用的是你裝置內建的語音。若你選到標示「線上」的語音，瀏覽器廠商會收到要念的文字。

## 使用前請先了解

- 命理是看清自己的一個角度，不是保證；重大決定請配合實際狀況、專業意見與家人共識。
- 健康部分只是體質傾向，不能取代醫師診斷。
- 分數是為了讓強弱一眼可比，不是吉凶的絕對值。
